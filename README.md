Overview
This repository contains the completed solutions for all four (4) core tasks assigned during the CodeAlpha Artificial Intelligence Virtual Internship Program. All projects were implemented using Python.

Task 1: Language Translation Tool (translator.py)
Goal: To create a command-line tool capable of translating user-input text using the googletrans library.

Files: translator.py

Dependencies: googletrans==4.0.0-rc1

Task 2: Creator for FAQs (faq_chatbot.py)
Goal: To build a simple knowledge-base application (chatbot) that answers questions by matching keywords against a predefined list of Frequently Asked Questions (FAQs).

Files: faq_chatbot.py

Dependencies: None (uses standard Python libraries)

Task 3: Music Generation (music_generator.py)
Goal: To implement a programmatic tool to generate a simple musical sequence (a C major scale) and save it as a MIDI file.

Files: music_generator.py, generated_music_task3.mid

Dependencies: music21

Task 4: Object Detection and Tracking (object_detector.py)
Goal: To implement a basic object detection application on a static image using the pre-trained YOLOv3 (You Only Look Once) model via the OpenCV library.

Files: object_detector.py, yolov3.cfg, yolov3.weights, coco.names, test_image.jpg

Dependencies: opencv-python, numpy

(Note: The large yolov3.weights file was downloaded separately.)
